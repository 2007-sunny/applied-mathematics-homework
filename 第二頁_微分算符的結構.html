微分算符 \(d/dx\) 的結構

應用數學 · Arfken 第 7 版 §5.3–5.7 · 第三次 AI 作業 第二頁

題目

考慮週期 \(2\pi\) 的函數空間 \(V = \mathrm{span}\{\cos kx, \sin kx\}\)，\(k = 1,\dots,N\)，內積 \(\langle f,g\rangle = \int_0^{2\pi} f^* g\, dx\)，以及 operator \(D = d/dx\)。(1) 在實數正交歸一基底 \(\{\cos kx/\sqrt{\pi}, \sin kx/\sqrt{\pi}\}\) 下寫出 \(D\) 的矩陣，求它的 adjoint，說明 \(D\) 是 anti-Hermitian、\(iD\) 是 Hermitian。(2) 用 unitary 矩陣 \(U\) 換到基底 \(\{e^{\pm ikx}/\sqrt{2\pi}\}\)，說明 \(U^\dagger D U\) 是對角矩陣，且本徵值、trace、determinant 不變。(3) 說明平移算符 \(e^{aD}\) 把 \(f(x)\) 變成 \(f(x+a)\)、是 unitary、就是 Taylor 展開，並且每個二維子空間 \(\mathrm{span}\{\cos kx, \sin kx\}\) 都是它的不變子空間。

物理原理解析

1. Linear operator → 矩陣（§5.3）

\(D\) 是線性的：\(D(\alpha f + \beta g) = \alpha Df + \beta Dg\)。選定正交歸一基底 \(\{\varphi_n\}\) 之後，\(D\) 就變成矩陣，第 \(n\) 行是 \(D\varphi_n\) 的係數向量：

\[D_{mn} = \langle \varphi_m, D\varphi_n\rangle, \qquad D\cos kx = -k\sin kx, \qquad D\sin kx = k\cos kx\]

2. Adjoint、邊界項、self-adjoint（§5.4）

Adjoint 由 \(\langle f, Dg\rangle = \langle D^\dagger f, g\rangle\) 定義。分部積分：

\[\langle f, Dg\rangle = \Big[f^* g\Big]_0^{2\pi} - \langle Df, g\rangle\]

邊界項會消失，完全是因為函數是週期的。於是 \(D^\dagger = -D\)（anti-Hermitian），而 \((iD)^\dagger = -i\,D^\dagger = iD\)（Hermitian）。這個性質取決於 domain，不只取決於 \(d/dx\) 這個式子：在 \([0,\infty)\) 上同一個式子就無法變成 self-adjoint。量子力學的 \(\hat p = -i\hbar\, d/dx\) 是 Hermitian，正是這個原因，所以本徵值是實數。

3. Unitary 換基底與 similarity transformation（§5.5–5.6）

兩組正交歸一基底之間的轉換矩陣是 unitary，\(U^\dagger U = I\)。係數向量變成 \(c' = U^\dagger c\)，operator 變成

\[D' = U^{-1} D\, U = U^\dagger D\, U, \qquad \frac{e^{ikx}}{\sqrt{2\pi}} = \frac{1}{\sqrt 2}\left(\frac{\cos kx}{\sqrt\pi} + i\,\frac{\sin kx}{\sqrt\pi}\right)\]

Unitary 的 \(U\) 保持內積（\(\|c'\| = \|c\|\)）。任何 similarity transformation 都保持本徵值、trace、determinant。在複數基底下 \(D\) 是對角的，本徵值 \(\pm ik\)：\(e^{ikx}\) 就是 \(D\)（也是動量算符）的本徵函數。

4. 平移 \(e^{aD}\) 與不變子空間（§5.5、§5.7）

\[e^{aD} f(x) = \sum_{n=0}^{\infty} \frac{a^n}{n!} f^{(n)}(x) = f(x + a), \qquad \left(e^{aD}\right)^\dagger = e^{aD^\dagger} = e^{-aD} = \left(e^{aD}\right)^{-1}\]

所以 \(e^{aD}\) 是 unitary，因為 \(D\) 是 anti-Hermitian；正如 \(e^{-iHt/\hbar}\) 是 unitary 因為 \(H\) 是 Hermitian。實數基底下每個區塊是轉 \(ka\) 角的旋轉；複數基底下是相位 \(e^{\pm ika}\)。\(D\) 把 \(\mathrm{span}\{\cos kx, \sin kx\}\) 映回自己，所以這個二維子空間是不變子空間：不同的 \(k\) 永遠不會混合，矩陣是區塊對角。在複數下，每個區塊還能再拆成兩個一維不變子空間 \(\mathrm{span}\{e^{\pm ikx}\}\)。
